# FactsLens

*See who's really behind the post.*

FactsLens watches public Bluesky activity live and spots **swarms**: groups of accounts acting together, such as posting near-identical text, sharing the same links at the same moment, or coming from freshly created accounts.

**NVIDIA Nemotron 3.5 Super VL** investigates each suspicious swarm:
- It looks at the images, video and linked websites.
- It names the manipulation techniques in plain language.
- It judges whether it's a real crowd or a staged one, and says "insufficient evidence" rather than guessing.

A **forecast** estimates how far a campaign will spread. Nemotron reads how strongly each audience is likely to react, and the forecast suggests which accounts moderators should act on first.

FactsLens **measures itself honestly**. It tests against fake campaigns generated by Nemotron and against real organic news bursts, and publishes its precision and false-positive rate on a public metrics page.

It never accuses anyone automatically: every report goes to a human reviewer.

## Built with

- **Hostinger VPS:** the app runs here, live, with a public URL.
- **NVIDIA Nemotron 3.5 Super VL** via NVIDIA Build: investigation, real-vs-staged judging, red-team test campaigns, audience modelling.
- **Aiven for Apache Kafka + PostgreSQL:** the event stream and the app's data.
- **Bluesky Jetstream + AppView:** the public data source.

## Getting started

1. Create your own `.env`.
2. Check that every integration works:
   ```
   uv run infra/check_access.py
   ```
3. Run the tests, then the pipeline (each service in its own terminal):
   ```
   uv run pytest
   uv run python -m factslens.ingest
   uv run python -m factslens.detector
   uv run python -m factslens.api        # http://127.0.0.1:8000
   ```
4. Deploy the last commit to the VPS: `infra/deploy.sh`
